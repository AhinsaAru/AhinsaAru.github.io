              TOOLSHOP/TS-142
              Example report
            

            
Cart accepts zero and negative quantities, producing a negative cart total

            

              New
              Severity: Major
              Priority: High
            

          


          

            

              

                
Description

                
The Quantity field on the Cart page has no lower-bound validation. Entering 0 or a negative number is accepted by both the UI and the API, and the line total and cart total become negative. The user can still click Proceed to checkout.

              


              

                
Environment

                
    
                  
  • URLpracticesoftwaretesting.com
    • 
                  
  • BrowsersChrome (latest), Firefox (latest)
    • 
                  
  • OSWindows 11
    • 
                  
  • UserLogged-in customer account
    • 
                

              


              

                
Steps to reproduce

                
    
                  
  1. Go to practicesoftwaretesting.com and log in with a valid customer account.
    2. 
                  
  2. Open any product (e.g. Combination Pliers) and click Add to cart.
    3. 
                  
  3. Open the Cart page.
    4. 
                  
  4. Clear the Quantity field, enter -2 and press Tab.
    5. 
                  
  5. Check the line total, the cart total and the Proceed to checkout button.
    6. 
                

              


              

                

                  
✓ Expected result

                  
    
                    
  • Quantity below 1 is rejected (minimum = 1).
    • 
                    
  • A validation message is shown: “Quantity must be at least 1”.
    • 
                    
  • Totals stay unchanged and checkout is blocked.
    • 
                  

                

                

                  
✗ Actual result

                  
    
                    
  • Quantity -2 is accepted without any message.
    • 
                    
  • Line total and cart total show -$28.30.
    • 
                    
  • Proceed to checkout is still enabled.
    • 
                  

                

              


              

                
Boundary values tested

                

                  
-1✗ accepted

                  
0✗ accepted

                  
1✓ ok

                  
2✓ ok
